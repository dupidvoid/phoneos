# **Phone.OS**
**What Actually Is Phone.OS?**
- Phone.OS Is an Online Phone, Only Given To My Closest Friends.
- It was an idea that sparked, because my school Ipads had a lot of restrictions. So I made Phone.OS, to avoid all of those restrictions.

 **What It Has**
 - Working AppStore (Limited currently)
 - Working Texting!
 - Working Contacts!
 - Working Notepad, Calculator, Password, Settings, StopWatch.
